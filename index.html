DHT22 (AM2302) ACTIVE

ESP32 Pin: GPIO 4 (Digital In/Out with 4.7kΩ pull-up)

Parameters: Ambient Temperature (°C) & Relative Humidity (%)

Range: -40 to 80 °C (±0.5°C) • 0 to 100% RH (±2% RH)

Sampling Period: 2.0 Seconds (500mHz)

Firmware Setpoint: Buzzer trigger at > 34.0 °C

MQ-135 Air Quality ACTIVE

ESP32 Pin: GPIO 34 (ADC1_CH6, Input Only)

Output Representation: Raw Analog ADC Value (0 - 4095)

Target Gases: NH3, NOx, Alcohol, Benzene, Smoke, CO2

Calibration Notice: Uncalibrated raw voltage reference. Not scaled to PPM.

NEO-6M GPS Receiver ACTIVE

ESP32 Hardware UART: Serial1 (RX = Pin 26, TX = Pin 27)

Baud Rate: 9600 Baud (SERIAL_8N1)

Parsed Sentences: NMEA GPRMC / GPGGA via TinyGPS++

Fix States: "GPS: NO FIX" / "Latitude, Longitude, Satellites"

ESP32 Pin: GPIO 25 (Digital Output)
